# The Open-Box Fallacy, project page

Project page for "The Open-Box Fallacy: Why AI Deployment Needs a Calibrated Verification Regime" by Phongsakon Mark Konrad, Tim Lukas Adam, Ane Cathrine Holst Merrild, Riccardo Terrenzi, Rebecca De Rosa, Toygar Tanyel and Serkan Ayvaz (arXiv 2605.10601, 2026). Live at https://aiml-sdu.github.io/open-box-fallacy-page/.

This repository holds the built static page only. The paper is a position paper and has no code release.
